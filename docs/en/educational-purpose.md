# 🎓 Educational Purpose

PlayerPuzzle is designed to:

* Turn correctly answering a content question into an immediate, visually rewarding combat event
  (a critical hit), rather than just a checkbox toward a grade
* Reuse a course's existing Question Bank, so content-fixation activities a teacher already
  maintains for Quiz can be repurposed without any migration
* Keep the rigor of assessment intact underneath the game — attempts are limited, answers are
  validated server-side, and the grade is designed to reflect genuine progress/performance (see
  [Game Modes](#game-modes)), never client-reported numbers
* Reward sustained engagement in a course-scoped way through the optional
  [PlayerHUD integration](#playerhud), without requiring any permanent economy for a course that
  doesn't want one

Suitable for:

* Any course already using `block_playerhud` for gamified progression
* Teachers who already maintain a Question Bank category for the same content and want a second,
  game-based way to reinforce it
* Institutions exploring gamified content-fixation as a complement to (not a replacement for)
  formal quizzes
