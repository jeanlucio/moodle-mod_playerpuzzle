# 📖 Usage

## For Teachers

1. Add a PlayerPuzzle activity to a course.
2. Choose a **Game Mode** — Campaign or Single Match — see [Game Modes](#game-modes).
3. Pick the Question Bank category the match will draw from.
4. Optionally set a **Minimum Questions per Match** and whether wrong answers should count
   against the grade.
5. Optionally configure the [PlayerHUD Integration](#playerhud) items, if `block_playerhud` is
   installed in the course.
6. Set the **Maximum Grade** — both grading formulas scale to it, never to a fixed `100`.

## For Students

1. Open the activity to reach the **Lobby** — it shows your current progress (Campaign mode),
   your PlayerHUD balance if configured, and any minimum-questions requirement.
2. Select **Play Game** to start (or resume) a match.
3. Match pieces to attack the boss, fill the energy bar to trigger a
   [Question Challenge](#questions), and answer correctly for a critical hit.
4. In Campaign mode, winning a phase never costs a new attempt — only losing does.
