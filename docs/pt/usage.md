# 📖 Como Usar

## Para Professores

1. Adicione uma atividade PlayerPuzzle a um curso.
2. Escolha um **Modo de Jogo** — Campanha ou Partida Única — veja [Modos de Jogo](#game-modes).
3. Escolha a categoria do Banco de Questões de onde a partida vai puxar questões.
4. Opcionalmente, defina um **Mínimo de Questões por Partida** e se respostas erradas devem
   contar contra a nota.
5. Opcionalmente, configure os itens de [Integração com o PlayerHUD](#playerhud), se o
   `block_playerhud` estiver instalado no curso.
6. Defina a **Nota Máxima** — as duas fórmulas de nota escalam por ela, nunca por um `100` fixo.

## Para Estudantes

1. Abra a atividade para chegar ao **Lobby** — ele mostra seu progresso atual (modo Campanha),
   seu saldo no PlayerHUD se configurado, e qualquer exigência de mínimo de questões.
2. Selecione **Jogar** para começar (ou retomar) uma partida.
3. Combine peças para atacar o chefe, encha a barra de energia para disparar um
   [Desafio de Pergunta](#questions), e responda certo para um acerto crítico.
4. No modo Campanha, vencer uma fase nunca consome uma nova tentativa — só perder consome.
